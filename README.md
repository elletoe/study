# study

- [공부 감시 타이머](index.html)
- [급식·시간표](meal/) — 나이스 교육정보 개방 포털 API로 오늘·이번 주 급식(알레르기 번호 포함)과 우리 반 시간표를 보여 줘요.
- [오답 복습](review/) — 틀린 문제 사진을 올리면 1 → 3 → 7 → 14일(그 뒤로 14일마다) 간격으로 다시 풀게 해 줘요. 난이도 하 2번 · 중 3번 · 상 4번(수학은 1번씩 더) 연속으로 맞히면 끝. 사진은 폰 안에만 저장돼요.
- [일본어 암기](japanese/) — 천재교과서 고등학교 『일본어』 단어·다이얼로그를 카드 내리기(클래스카드처럼)·손글씨(애플펜슬, AI 인식)·자판으로 외워요. 일본어↔한국어 방향 바꾸기, 다이얼로그 열람, 약한 것·별표 모아 보기. 히라가나·가타카나 외우기는 기본으로 들어 있어요. 아이패드 기준. 교과서 내용은 `japanese/data.js`에 넣어요.

아이폰 사파리에서 공유 → 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
